# 從自己的寫手到製作流程

編譯時不必執行正文。使用者要求開始寫、續寫或改稿時，載入 `creative-production`，傳遞：

- 已選的那套完整寫手指令與版本，不把多套候選混在一起。
- 受眾、文類、風格、資訊密度、篇幅及計數口徑。
- 大綱版本；敘事系列的人物設定版本、篇章 ID、前章摘要及未解事項。
- 使用者已核准／尚待確認的項目與下一個交付物。

輸入契約寫明：上游版本改變先檢查依賴，禁止默用舊角色或改名；前篇伏筆本篇回收或明示延續。非敘事用論據／資料來源取代角色與伏筆，不注入小說節奏。

生成指令內只保留寫手需要的契約，JSON、QA、素材管理及費用授權留在製作流程；正文不混進專案表。
