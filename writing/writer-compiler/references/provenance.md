# 來源與個人版本

這份是使用者自有 writer-compiler v3.6 的 Hermes 個人適配版 v3.7，來源位於 本庫 `writing/writer-compiler/` 的歷史版本。

保留：逐段互動、領域動態判定、多候選、大綱先於人物、版本與交稿自檢、通用 Markdown 複製框。

個人適配：補齊 S1C 的明確流程；以實際 `clarify` 工具與其 Other 行為綁定；直接要正文時交給 creative-production；不保留未查證的品牌模型策略。沒有把 BookFlow 或漫劇規則混入通用寫手模板。

本庫保存可部署的個人適配版本。本機已安裝技能不會隨 Git 更新自動同步；更新時先備份並比較兩端，再同步指定檔案，避免覆蓋本機新修改。
